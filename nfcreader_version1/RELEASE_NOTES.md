# Smart Badge Android App v1.0

## 🎉 First Official Release

A complete NFC smart badge companion app with image processing, cloud storage, and NFC tag writing capabilities.

## ✨ Key Features

- **Image Processing**: Floyd-Steinberg dithering algorithm for high-quality image conversion
- **Cloud Storage**: Automatic GitHub upload with Raw URL generation  
- **NFC Writing**: Standard NDEF URI record support for all NFC tag types
- **E-paper Ready**: Optimized for 2.9-inch e-paper displays (128×296 pixels)

## 🔧 Technical Specs

- **Min Android**: 8.0 (API 26)
- **Target Android**: 14 (API 34) 
- **APK Size**: 4.2MB
- **Permissions**: NFC, Storage, Camera

## 🚀 Workflow

1. Select Image → Floyd-Steinberg Processing → GitHub Upload → NFC Write

## 📥 Installation

Download `smart-badge-v1.0-signed.apk` and install on NFC-enabled Android device.

## 🐛 Known Issues

- Requires stable network for GitHub upload
- First-time permissions setup needed
